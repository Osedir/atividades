Prompt de criação do projeto e do arquivo inicio.html:
"Vamos montar um projeto de gestão escolar utilizando apenas HTML e CSS.  Quero estruturar em uma pasta chamada "gestaoEscolar" com inicio.html, arquivos CSS externos, uma pasta chamada "imgs" para armazenar as imagens das páginas e outra pasta chamada "pags" para os demais arquivos HTML. No meu arquivo inicio.html, faça um banner esquerdo com uma imagem contendo a seguinte frase: "Sistema de Gerenciamento Escolar v1.0" e abaixo dela livros para fins de ilustração. Faça o conteúdo do lado direito com 2 <a href> centralizados (horizontalmente e verticalmente), um abaixo do outro (espaçados por uma linha) com as respectivas legendas: "Entrar como Aluno" e "Entrar como Professor"."

Prompt de criação dos arquivo aluno.html e professor.html:
"Ok, vamos para os arquivos aluno.html e professor.html. As duas páginas serão praticamente idênticas (mantendo a mesma estrutura do inicio.html). A página aluno.html terá do lado esquerdo uma imagem com o título "Aluno" e abaixo dela um menino segurando livros no braço e de mochila nas costas, do lado direito implemente um <input type="number"> com placeholder escrito "Matrícula", passe uma linha e implemente outro <input type="password"> com placeholder escrito "Senha", passe uma linha e implemente um <button> escrito "Entrar". Na página professor.html apenas altere o banner esquerdo, gerando uma imagem contendo o título "Professor" e abaixo dela um professor de óculos segurando um livro na frente de uma lousa."

Prompt de criação dos arquivos paginaaluno.html e paginaprof.html:
"Agora vamos ao arquivo paginaaluno.html. Nesta página, organize o menu do aluno implementando uma <ul> contendo os seguintes <li>: Disciplinas, Horários, Notas e Frequência. Para o arquivo paginaprof.html, faça com outros 4 elementos: Minhas Turmas, Planos de Aula, Lançar Notas, Registrar Frequência. Ao final de cada lista, adicione o botão Sair para retornar ao inicio.html."

"Para finalizar a parte relacionada a aluno, crie os arquivos disciplinas.html, horarios.html, notas.html e frequencia.html, conecte-os aos seus respectivos itens na lista em paginaaluno.html, implemente <table> em cada um dos arquivos e os preencha com elementos e valores fictícios.
